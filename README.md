
# MTK Store – Sistema de Gerenciamento de Loja de Roupas

## 🎨 Interface do Sistema

O MTK Store possui uma interface gráfica desenvolvida em C# Windows Forms, com design moderno, organizado e delicado, utilizando tons de rosa e branco.

O sistema conta com um menu lateral para facilitar a navegação entre as funcionalidades, proporcionando uma experiência simples e intuitiva.

### Telas do Sistema

- **Tela de Login** – Acesso ao sistema por meio de usuário ou e-mail e senha.

- **Tela de Cadastro** – Cadastro de novos usuários.
- **Tela Inicial** – Página principal do sistema.
- **Tela de Produtos** – Cadastro, alteração, exclusão e consulta de produtos.
- **Tela de Clientes** – Gerenciamento das informações dos clientes.
- **Tela de Vendas** – Registro de vendas, seleção de clientes, produtos e formas de pagamento.
- **Tela de Relatórios** – Consulta das vendas realizadas.

## 📋 Descrição

O MTK Store é um sistema desktop desenvolvido em C# Windows Forms para gerenciamento de uma loja de roupas. O projeto utiliza MySQL como banco de dados e permite organizar produtos, clientes, estoque e vendas, além de oferecer telas de login e cadastro para controlar o acesso ao sistema.

## 🚀 Tecnologias Utilizadas

- **C#** – Linguagem de programação.
- **Windows Forms** – Desenvolvimento da interface gráfica.
- **MySQL** – Sistema de gerenciamento de banco de dados.
- **ADO.NET** – Conexão e comunicação com o banco de dados.
- **Visual Studio** – Ambiente de desenvolvimento.
- **MySQL Workbench** – Gerenciamento do banco de dados.

## 🎯 Funcionalidades

- ✅ **Login** – Acesso ao sistema.
- ✅ **Cadastro de Usuários** – Registro de contas de acesso.
- ✅ **Cadastro de Produtos** – Inclusão de roupas e informações dos produtos.
- ✅ **Gerenciamento de Produtos** – Alteração, exclusão e consulta.
- ✅ **Cadastro de Clientes** – Registro e gerenciamento de clientes.
- ✅ **Controle de Estoque** – Acompanhamento da quantidade de produtos.
- ✅ **Registro de Vendas** – Realização e armazenamento das vendas.
- ✅ **Formas de Pagamento** – Registro da forma de pagamento utilizada.
- ✅ **Relatórios** – Consulta das vendas realizadas.

## 🗄️ Banco de Dados

O sistema utiliza o banco de dados MySQL, denominado `mtk_store`, para armazenar e organizar as informações.

Principais tabelas:

- `usuarios` – Armazena os dados de acesso dos usuários.
- `produtos` – Armazena os produtos cadastrados.
- `clientes` – Armazena os dados dos clientes.
- `vendas` – Registra as vendas realizadas.
- `itens_venda` – Armazena os produtos pertencentes a cada venda.
